# Restaurant Assistant

A simple AI-powered restaurant chatbot built with Python, the Groq API,
and the OpenAI-compatible Python client. The assistant can answer
restaurant-related questions, recommend menu items, and respond to
customer messages while maintaining a short conversation history.

## Project File

-   `Restaurant_Assistant.ipynb` --- Google Colab/Jupyter Notebook
    containing the complete implementation.

## Features

-   **Groq API integration** using the OpenAI Python client.
-   **Restaurant-focused system prompt** for friendly customer
    assistance.
-   **Menu dictionary** containing sample restaurant items and prices.
-   **Order data example** using a Python dictionary.
-   **JSON handling** to serialize and deserialize order information.
-   **Price calculation** through the `get_price()` function.
-   **Function decorator and logging** to display function calls and
    results.
-   **Conversation history** so the assistant can use recent chat
    context.
-   **Error handling** for API rate limits, connection failures, and
    other exceptions.
-   **Interactive chat loop** that continues until the user enters
    `bye`, `exit`, or `quit`.

## Setup and Installation

### 1. Open the notebook

Upload `Restaurant_Assistant.ipynb` to [Google
Colab](https://colab.research.google.com/) or open it in Jupyter
Notebook.

### 2. Install the required package

The first notebook cell installs the OpenAI Python SDK:

``` python
!pip install -q openai
```

### 3. Configure the Groq API key

The notebook reads the API key from Google Colab Secrets. Add a secret
with:

-   **Name:** `GROQ_API_KEY`
-   **Value:** Your Groq API key

In Colab, open the **Secrets** panel (key icon), add the secret, and
enable notebook access for it.

The notebook configures the client as follows:

``` python
from google.colab import userdata
from openai import OpenAI

client = OpenAI(
    api_key=userdata.get("GROQ_API_KEY"),
    base_url="https://api.groq.com/openai/v1"
)

MODEL = "openai/gpt-oss-120b"
```

Keep your API key private. Do not paste it directly into a notebook
shared publicly or commit it to a public repository.

### 4. Run the notebook

Run the cells from top to bottom. The notebook first tests the API
connection and assistant response, then demonstrates the restaurant
prompt, menu, order data, price calculation, and conversation functions.

When the interactive chat cell starts, type a message at the `You:`
prompt.

To stop the chat, enter:

``` text
bye
```

You can also enter `exit` or `quit`.

## Main Functions and Data

### `get_price(item, qty=1)`

Returns the total price for a menu item and quantity. It checks whether
the item exists and whether the quantity is greater than zero.

Example:

``` python
get_price("veg biryani", 2)
```

### `log_call(func)`

A decorator that logs the name, arguments, and return value of a
function call.

### `chat(user_text)`

Adds the user's message to the conversation history, sends the recent
messages to the Groq model, handles API errors, stores the assistant's
reply, and returns it.

The notebook uses `MAX_TURNS = 8` to limit the recent conversation
messages sent with each request, in addition to the system prompt.

## Example Interaction

``` text
You: Suggest a vegetarian meal.

You: What is the price of veg biryani?
Bot: The sample menu lists Veg Biryani at ₹180.
```

Assistant responses are generated by the language model and may vary.
The example prices come from the notebook's local sample menu.

## Important Limitations

-   This is a learning/demo chatbot, not a production restaurant
    ordering platform.
-   The menu and prices are sample data maintained in the notebook.
-   The notebook does not connect to a live restaurant inventory,
    delivery service, payment gateway, or order-management system.
-   It does not actually place or confirm restaurant orders or
    reservations.
-   Availability, delivery times, and other real-world details must be
    verified with the restaurant.
-   API access requires a valid Groq API key and may be subject to
    account limits.
